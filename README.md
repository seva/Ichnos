# ichnos

Stylometric detector for Claude Mythos signatures in Glasswing-credited vulnerability advisories.

The project name is from Greek ἴχνος (*ichnos*), "footprint" or "track." Mythos has moved on; what we study is the textual trace it left in advisory prose.

Built on the [epistegrity](https://github.com/seva/epistegrity) methodology scaffold.
