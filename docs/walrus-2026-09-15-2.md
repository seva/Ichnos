## Learnings

- **A test suite that tests a seam cannot see the boundary it stands in for.** The shipped `get_context` recursed infinitely on the real call path while 16 tests passed — they called the seam. Fix: tests invoke `app.call_tool` (public path) from birth; the seam is deleted (banned pattern).
- **gh is not on PATH anywhere on this host** (`where.exe gh` fails; the CLI lives at a standard install path). Adapters must fall back to standard locations — and tests must not assume host state (deterministic `_GH_LOCATIONS` fixtures).
- **Subprocesses under an MCP stdio server must never inherit the transport.** The token subprocess hung 10s on the server's stdin pipe; `stdin=DEVNULL` is now a pinned property.
- **`await client.get(...).raise_for_status()` binds the method call on the coroutine** — attribute access chains before await. Assign the response, then chain.
- **PowerShell parse errors abort the entire command block** — a backup `Copy-Item` sharing a block with a parse error never executes. Cost: one host-config write went in unbacked (verified post-hoc; recorded).
- **`mcp` 2.x renamed FastMCP → MCPServer** — lineage is v1; pinned `<2`.
- **Operator-run manual tests are a verification instrument**: a numbered prompt with expected outcomes produced the L2 proof verbatim, and the operator's report surfaced the `as_of` contract defect (uptime vs epoch) that neither review cycle caught.
- **Recurrence is a signal, not a nuisance**: the record-staleness class recurred because commit-time record sync relies on Steward discipline, not an enforcer — the doctrine's Revision escalation is the correct response, not another repair.
