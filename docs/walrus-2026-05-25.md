## Learnings

- The dashboard is a static Cloudflare site exposing machine-readable JSON (`data/ledger.json` 1,611 entries; `data/payload.json` 992 KB) plus per-finding `preimage.json` — no scraping, no API key, tamper-evident via SHA-3-512.
- **Mythos text is Anthropic-authored** ("Anthropic's analysis, sealed at approval"), human-reviewed before sealing, *disclosed* by named external firms (nginx → "Calif"; Oracle is a partner per Coopersmith). Layered authorship bounds OQ#5.
- **CVE/GHSA descriptions are maintainer/CNA-authored** (`facts@wolfssl.com`, `f5sirt@f5.com`, `security@temporal.io`) — never Mythos. This single fact is the hinge of the text-scope problem.
- **Identifier resolution is partial/inconsistent** (2026-05-25): some CVEs resolve in NVD (nginx, temporal, wolfSSL), one absent (mastodon CVE-2026-46348); most dashboard GHSAs 404 on GitHub (libyang, mastodon, freerdp), one resolves with a *different* CVE mapping (Ghost → CVE-2026-26980).
- The oss-sec "enumeration" the task assumed is a **single Coopersmith pointer post** (2026-05-23) to the dashboard — not an independent source.
- Corpus unit is the **finding (`ant_id`)**; CVE/GHSA↔finding is many-to-many (nginx's 2 findings share one CVE; freerdp's 3 share a GHSA cluster).

## Risks

- **Central risk — the literal comparison is ill-posed.** Mythos-authored text (dashboard) has no same-author control; pairing it with maintainer control text is a source/format confound that held-out-maintainer does **not** catch, and the act-tier bar (implied d≈1.19) is primed to mislabel it as a signature.
- **Underpowered.** The held-out-maintainer AUC is not computable today (11 singleton maintainers; one usable author class). Random-split is only marginally powered for a large effect, with wide CIs (AUC 0.80 at n=27 → CI [0.68, 0.92]).
- **Controls cannot be verified non-Mythos** from public data (unrevealed findings hide their project; self-CNAs need not credit the finder) → contamination biases toward a null.
- **Retrievability is partial and time-dependent** → Option A text may be unavailable for some entries right now.
- Analysis is frozen to the 2026-05-22 snapshot (rev 1); the live dashboard will drift as windows close.
