# Horizons

**PRAROC-7** — Progressive RAROC. The P is the process: progression *is* the paradigm, so the numeral is a bound, not an obligation. The ladder tops at seven positions; a commitment class runs at PRAROC-n, n set by what the commitment costs (refinement rule below). Reading 7 as a version or as the default set is the drift this line exists to kill.

Doctrine for bounded operators: commitments drift, readings expire, and some margin is not recoverable. `CYCLE.md` selects and ranks; this file governs what may never be spent and what is excluded before any ranking runs. Copy verbatim. Canonical prose: `docs/praroc-paradigm.md`. Per-project compiled constraints: `docs/scope.md` (Terminal bound section).

## Refinement rule

A plan is a sequence of position sets, each refining the last. **Split a position when two distinct operations are being performed inside it.** Refinement level is set by what the commitment costs — a recoverable commitment run at a fine set fails the paradigm's own criterion; an irrecoverable commitment run at a coarse set cannot hold its failure mode.

| Set | Positions | Split introduced |
|---|---|---|
| 1 | Now | — |
| 2 | Now · Later | measure against forecast |
| 3 | Now · Far · Unreachable | respond against accept |
| 5 | Now · Near · Far · End · Unreachable | state against check |
| 7 | Now · Fluctuation · Adaptation · Revision · Acceptance · Celebration · Reinception | adapt against rebuild; pause against derive |

Each set carries a split signal — the observable that the next refinement is now required. Under-refinement is self-concealing; the signals are what make it detectable.

## Checkable claims

A claim is checkable when its correction condition is stated in terms independent of the claim. Self-referential tolerance (*works as long as things stay the same*) absorbs every failure as evidence of change and is unfalsifiable. A claim without an independent channel is not a forecast; it has no resolution record and cannot be scored.

Capacity readings are bounded by substrate drift, not by calendar, and they expire. Dropping the drift term silently converts *can* into *am* — a bounded reading becomes a standing property with nothing that can arrive to close it. Tolerance is itself a forecast and requires a resolution record like everything else. Unexercised capacities generate no failure record: the regions with no data are the regions of highest confidence.

---

## Terminal bound

Later carries one property and no content: **it ends.** The bound is never consulted at the decision point — its content is unknowable and consulting it returns nothing actionable. Its presence does the work. Derive it once, compile it into standing constraints in `docs/scope.md`, check the compiled constraints against the current reading each Orient. Continuous attention to it is not licensed; skipped derivation produces no signal until arrival and is indistinguishable from compiled-in daily operation.

**The delusion of perpetuity is not a belief anyone asserts. It is what obtains when the position is left empty.** An unbounded terminal position reopens every trade of irrecoverable margin against recoverable return, and each such trade succeeds visibly while the margin consumed generates no signal.

## Filter before rank

**Far** — where predictions fail and responses exist: risk. **End/Unreachable** — where no response exists: threat. Recoverable capital and irrecoverable margin are non-convertible denominators; past the boundary, return leaves the unit entirely — capital spent buys the capacity to keep spending, not the thing being bought.

**Therefore the boundary is a filter applied before ranking, not a term inside a sum.** Any commitment negative there is excluded regardless of near return. The filter fires on compiled structure, never on disposition and never on a computed ratio: a commitment whose near return degrades its own capital keeps a locally valid ratio the whole way down.

---

## Profile, not total

Score return per position; do not aggregate. Now is measured (recoverable denominator); Far is heuristic, tagged as such with parameters exposed; the boundary is a filter, no ratio. The output is a shape — the decision-relevant quantity is where return inverts across positions, which no single-horizon ratio produces and no total carries. Weighting positions into one number *is* the decision, returned to the aggregator hidden.

---

## Allocation

- **Within a commitment:** compare across horizons. Now against Far — the inversion point. Far terms are discounted for being estimates (the P in V × P), never for being distant; collapsing the epistemic discount into a temporal one makes every deferred return look worse than it is.
- **Across commitments:** compare **marginal return on the next increment of budget**, at each commitment's current phase. A level against a margin is a category error — a newcomer's full profile weighed against an incumbent's remaining margin credits the newcomer with returns already banked. This is the mechanism of serial abandonment. Score every side by what its next increment buys; where one rate is measured and the other projected, the projection carries an epistemic discount — applied as a discount, not disqualification.
- **Switching** has its own denominator: transition cost, usually living in the heuristic region. Marginal differences do not justify a switch.

## Set 5 mechanics

Three states (Now, Far, Unreachable) and two checks (Near — first crossing, a successor prediction must be made; End — last crossing, no successor prediction is useful). States bound the predictive region; checks are the only points where the world scores what was held.

Decompose each commitment into three to five independently drifting terms — fastest drift relative to the commitment interval, weighted by consequence. **Terms below the cut are registered as assumed non-drifting, explicitly:** a term with no horizon is treated as non-drifting either way; stating it converts a silent default into a claim. Positions fire per term, asynchronously.

On Near firing, re-derive the far positions from the current reading — they remain predictions because they are reprojected before being approached. End is unreachable by construction: drift large enough to bring it closer has already crossed Near.

**Cadence.** Every Now: compiled constraints checked against the current reading — one comparison, no recomputation. On Near: re-derivation. A scheduled sweep for crossings absorbed without registering is the only admissible use of a calendar — backstop, never ground, its cadence calibrated by the record of missed crossings.

**Scope condition: continuity.** Covered — continuous drift in both directions. Uncovered — discontinuity (collapse before Near; survival past End). Neither updates any threshold: a survived End is an unrepeatable event the model correctly declined to forecast, and updating on it fits noise at the one place noise is unaffordable. Discontinuity is managed structurally — by not holding commitments whose failure requires a check that may never fire — not by cadence or tolerance.

**Scale condition.** The cycle closes at project scale, where a successor state exists and ends recur — so the record of where the End fell against where it was called accumulates and calibrates the next one. It does not close at operator scale: there, End has no successor, and extending the cycle universally unbounds the terminal position and removes the filter. Terminal thresholds are learnable only in fast contexts; only from there is anything transferable to the positions that occur once.

## Set 7 mechanics

Spans: **1–3 risk management** (responses exist, capital recoverable, readings scored by the next measurement). **4 is the mode shift** — mitigation stops, disposition begins; running risk management here is the override signature. **4–5 exit management**, where the filter lives. **6–7 the return** — cessation, then rebuild.

- **Adaptation vs Revision.** Adaptation responds within the current term set; Revision rebuilds the term set when a term once assumed negligible now dominates — the decomposition, not the estimate, has expired. Revision is unsignaled: nothing fires on it. **Diagnostic: repeated successful local repairs with no aggregate recovery.**
- **Acceptance.** Disposition: *longevity* (preserve the substrate, extend current positions, produce no successor) vs *seeding* (invest in a successor, preserve the form, release the substrate — closes the cycle). The branches are not equally available across the interval: seeding draws on margin longevity consumes. **Ordering matters more than content.**
- **Celebration vs Reinception.** Cessation, then derivation; merged, the successor is derived under the pressure the cessation was meant to remove. Reinception builds the successor's term set from the changed substrate — importing the previous terms, thresholds, and compiled rules is **reinstatement**, not reinception.

## Error signatures (audit checklist)

| Signature | Form | Discriminator / fix |
|---|---|---|
| End reached more than once | Near misread as End, or override | Did a successor forecast exist and resolve, or did continuation follow only from the absence of a stopping rule? Misidentification recalibrates cheaply; override is running on no useful prediction |
| End never approached | Horizon set loose enough to be unreachable by construction | The bound does no work; re-derive |
| Unbounded terminal position | Terminal value or perpetuity term in the plan | Removes the filter; nothing records how many responses remain (the pivot assumption) |
| Goal-shaped terminus | One specified terminal state, complement unpriced; no successor, no drift | Margin-intact and margin-spent failure become the same point. The far position is a margin, not a state |
| Problem-to-solution planning | One position (a check, not a state) with a response attached | No baseline, no Revision (recurring problems get repeated solutions), no disposition mode (continuation by default — override by construction), no filter, no Reinception |
| Cross-scale mismatch | Commitment scored on the entity's horizon, spending the operator's margin | Name whose substrate each term drifts in |
| Reinstatement | Successor derived by importing old terms, thresholds, rules | Rebuild the term set from the changed substrate |
| Under-refinement | Commitment run at a set too coarse to hold its failure mode | Self-concealing — check the split signals |
